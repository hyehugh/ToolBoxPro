# ToolboxPro - Promotion Assets

This directory contains all the promotion materials for ToolboxPro.
Use these drafts to publish on various platforms.

## Files

- `devto-article.md` — Full Dev.to technical article
- `reddit-sideproject.md` — r/SideProject post draft
- `reddit-webdev.md` — r/webdev post draft
- `show-hn.md` — Hacker News Show HN draft
- `indiehackers-post.md` — Indie Hackers journey post
- `producthunt-assets.md` — Product Hunt launch materials
- `twitter-strategy.md` — Twitter/X content plan
- `seo-comparison-posts.md` — Topics for SEO comparison articles

## How to Use

1. Open the file for the platform you want to post on
2. Copy the content
3. Paste and publish on the platform
4. Check back for comments and reply within 2 hours
