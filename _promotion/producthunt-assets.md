## First Comment (paste right after launching)
Hey Product Hunt! 👋

I built ToolboxPro because I was tired of tool sites that require uploading my private files to their servers just to format JSON or compress an image.

**What makes ToolboxPro different:**
- Every tool runs in YOUR browser — zero server-side processing
- Your files never touch a server (seriously, there is no server)
- No signup, no accounts, no data collection
- Works offline after first load
- 100+ tools across 8 categories

**Tools include:** JSON formatter/diff/converter, regex tester, JWT decoder, PDF merger/splitter/rotator, image compressor/resizer/converter, color tools, QR/barcode generator, text utilities, and more.

Built with Next.js 15, Tailwind v4, TypeScript. Powered by pdf-lib and Canvas API.

All free, all in-browser: https://trytoolboxpro.com

Happy to answer any questions about the architecture!
