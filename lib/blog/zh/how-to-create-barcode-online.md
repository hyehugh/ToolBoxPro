## 了解条形码类型

并非所有条形码都一样。现有数十种条形码码制（格式），每种都针对特定用途而设计。以下是你最常遇到的几种：

### Code 128

Code 128 是使用最广泛的线性（一维）条形码格式之一。它可以编码全部 128 个 ASCII 字符，功能极为全面。Code 128 条形码紧凑，能在很小的空间内存储较高密度的数据。

**最适合：** 物流标签、库存跟踪、物流管理和通用标识。如果你要为企业内部使用创建条形码，Code 128 通常是最佳选择。

Code 128 有三个子类型：
- **Code 128A** —— 大写字母、数字和控制字符
- **Code 128B** —— 大小写字母和数字
- **Code 128C** —— 仅数字对（数字编码最紧凑）

大多数条形码生成器会自动为你的数据选择最优子类型。

### EAN-13

EAN-13（欧洲商品编码）是全球零售产品上的标准条形码。它编码一个 13 位数字，用于销售点系统中的产品识别。

**最适合：** 零售产品、图书出版（ISBN 是 EAN-13 的子集），以及在商店销售的任何产品。如果你在零售渠道销售实体产品，你很可能需要 EAN-13 条形码。

前 2-3 位数字标识原产国，接下来的 4-6 位标识制造商，其余数字标识具体产品。最后一位是自动计算的校验位。

### EAN-8

EAN-8 是 EAN-13 的小型版本，仅编码 8 位数字。它专为空间有限的小型产品而设计，如糖果、小型化妆品或其他紧凑型商品。

**最适合：** EAN-13 条形码太大、无法放在包装上的小型零售产品。

### Code 39

Code 39 是最早的条形码码制之一，至今在非零售环境中仍然流行。它编码大写字母（A-Z）、数字（0-9）以及少量特殊字符（-、.、$、/、+、% 和空格）。

**最适合：** 军事应用、汽车工业、医疗保健和内部跟踪系统。Code 39 常用于美国政府 和军事应用。

对于相同的数据，Code 39 条形码比 Code 128 更宽，但它更简单、历史更悠久，因此被遗留系统广泛支持。

### UPC-A

UPC-A（通用产品代码）是主要在美国和加拿大用于零售产品的标准条形码格式。它编码 12 位数字，是 EAN-13 的前身（前导零的 EAN-13 条形码等同于 UPC-A 条形码）。

**最适合：** 主要在北美市场销售的产品。许多零售商同时接受 UPC-A 和 EAN-13。

### ITF-14

ITF-14（交叉 25 码）是一种仅数字条形码格式，精确编码 14 位数字。它主要用于包装标签 —— 装有多个零售产品的外箱和运输容器。

**最适合：** 运输纸箱、托盘标签和仓库库存管理。ITF-14 条形码通常印刷在瓦楞纸板包装上。

### QR 码

虽然从技术上讲是二维码而非线性条形码，但 QR 码因其巨大的流行度值得一提。QR 码可以存储多达 4,296 个字母数字字符，几乎可以被任何现代智能手机摄像头读取。

**最适合：** URL、联系信息、Wi-Fi 凭证、菜单、营销材料，以及任何需要在狭小空间内存储大量数据的场景。

**专业提示：** 对于将被标准条形码阅读器扫描的条形码，坚持使用黑底白字。彩色条形码可能在某些设备上无法可靠扫描。

- **SVG** —— 矢量格式，可无限缩放且不失真。是印刷材料和专业应用的理想选择。
- **PDF** —— 通用格式，易于嵌入文档并直接打印。

## 条形码打印技巧

生成条形码只是完成了一半 —— 正确打印同样重要。以下是关键打印技巧：

### 分辨率很重要

对于打印的条形码，至少追求 **300 DPI**（每英寸点数）的分辨率。低分辨率、边缘锯齿的条形码可能无法正确扫描。如果打印小尺寸条形码，可能需要更高的分辨率。

### 尺寸要求

每种条形码格式都有最小和最大尺寸要求：

- **EAN-13：** 标准尺寸为 37.29mm × 25.93mm，可在 80% 到 200% 之间缩放
- **Code 128：** 最小模块宽度 0.264mm（10 mil）以保证可靠扫描
- **QR 码：** 最小尺寸取决于数据密度，一般至少 2cm × 2cm

不确定时，宁可把条形码做大一些也不要做小。大条形码比小条形码更容易扫描。

### 静区

每个条形码两侧都需要留白（静区）。对于 Code 128，静区宽度应至少为最窄条宽度的 10 倍。对于 QR 码，静区应至少为 4 个模块宽。

### 避免常见打印错误

1. **不要拉伸或扭曲**条形码。始终保持正确的宽高比。
2. **不要将条形码放在曲面上**，除非使用专门的曲面打印技术。
3. **避免在闪亮或反光的表面上打印**，这会干扰扫描器的光线反射。
4. **测试你的条形码** —— 在大批量打印前，用多个设备扫描验证。
