### 了解颜色格式

在能够有效地取色之前，你需要了解 Web 上表示颜色的不同方式。每种格式都有其优势，知道何时使用哪种格式会让你更加高效。

#### HEX（十六进制）

HEX 是 Web 上最常见的颜色格式。它由一个井号后跟六位十六进制数字组成，其中前两位代表红色，中间两位代表绿色，最后两位代表蓝色。

```
#FF5733  →  红色: FF (255), 绿色: 57 (87), 蓝色: 33 (51)
#000000  →  黑色
#FFFFFF  →  白色
#6366F1  →  靛蓝（流行的 Tailwind 颜色）
```

HEX 还支持三位数的简写形式，当每个通道使用重复数字时：`#F00` 等同于 `#FF0000`（纯红）。一些现代浏览器还支持8位 HEX（`#RRGGBBAA`）用于 alpha 透明度。

#### RGB（红、绿、蓝）

RGB 对每个通道使用0到255的十进制值。语法为 `rgb(红, 绿, 蓝)`。

```css
/* 与上面相同的颜色，用 RGB 表示 */
rgb(255, 87, 51)   /* #FF5733 */
rgb(0, 0, 0)       /* 黑色 */
rgb(255, 255, 255) /* 白色 */
rgb(99, 102, 241)  /* 靛蓝 */
```

RGB 更适合通过编程方式调整，因为它使用十进制数字。`rgba()` 变体增加了 alpha 通道用于透明度：`rgba(99, 102, 241, 0.5)`。

#### HSL（色相、饱和度、明度）

HSL 以更接近人类思维方式来描述颜色。语法为 `hsl(色相, 饱和度%, 明度%)`：

- **色相**：在色环上的位置（0-360）。0是红色，120是绿色，240是蓝色。
- **饱和度**：颜色的强度（0% = 灰色，100% = 全彩）。
- **明度**：亮度（0% = 黑色，50% = 纯色，100% = 白色）。

```css
hsl(9, 100%, 60%)    /* #FF5733 — 鲜艳的橙红色 */
hsl(0, 0%, 0%)       /* 黑色 */
hsl(0, 0%, 100%)     /* 白色 */
hsl(239, 84%, 67%)   /* #6366F1 — 靛蓝 */
```

HSL 对于创建配色方案极具价值，因为你可以保持相同的色相，仅改变饱和度和明度来获得协调一致的外观。使用 `hsla()` 可添加透明度。

### 颜色格式对比

| 格式 | 最适合 | 优点 | 缺点 |
|------|--------|------|------|
| HEX | CSS 值、设计交付 | 紧凑、通用支持 | 手动阅读和调整困难 |
| RGB | 编程式颜色操作 | 十进制数字、易于计算 | 语法冗长 |
| HSL | 创建配色方案、主题化 | 人类可读、直观调整 | 设计工具中较少使用 |
| CMYK | 印刷设计、物理媒介 | 匹配打印机墨水行为 | CSS 不支持 |
| LAB/OKLCH | 感知均匀渐变 | 最接近人类视觉 | 浏览器支持有限 |

### 开发者的色彩理论基础

你不需要是设计师才能选好颜色，但了解一些基础知识会大大改善你的结果。

#### 色环

色环将色相排列成一个圆圈。原色（红、黄、蓝）均匀分布。间色（橙、绿、紫）位于它们之间。复色填补剩余的间隙。

从色环衍生出的常见配色方案包括：

| 方案 | 描述 | 示例 |
|------|------|------|
| 单色 | 同一色相的不同明度/饱和度 | 浅蓝 → 中蓝 → 深蓝 |
| 类比 | 三个相邻色相 | 蓝 → 蓝绿 → 绿 |
| 互补 | 对立的色相 | 蓝 ↔ 橙（高对比度） |
| 三元 | 三个均匀分布的色相 | 红 → 黄 → 蓝 |
| 分裂互补 | 一个色相 + 其互补色两侧的相邻色 | 蓝 + 黄橙 + 红橙 |

#### 60-30-10 法则

一个简单的 UI 颜色比例规则：
- **60%** —— 主导/中性色（背景、大面积区域）
- **30%** —— 辅助色（页头、导航）
- **10%** —— 强调色（按钮、链接、行动号召）

这可以在不让用户感到压迫的情况下创建视觉层次。使用 [/tools/color-picker](/tools/color-picker) 中的工具，找到在每个比例中协调一致的色调。

#### 无障碍和对比度

颜色选择不仅仅关乎美观——也关乎可用性。Web 内容无障碍指南（WCAG）要求：

- **AA 标准**：正常文本对比度至少4.5:1，大号文本至少3:1
- **AAA 标准**：正常文本对比度至少7:1，大号文本至少4.5:1

当你选择颜色时，将其与对比的前景色配对。一个常见的错误是在白色背景上使用浅灰色文字（#999）——那只有大约2.7:1的对比度，远低于 AA 标准。

```css
/* 良好的对比度组合 */
body {
  background: #FFFFFF;       /* 白色 */
  color: #1F2937;            /* 深灰色 — 约16:1对比度 ✓ */
}

/* 不良的对比度组合 */
body {
  background: #FFFFFF;       /* 白色 */
  color: #9CA3AF;            /* 浅灰色 — 约2.7:1对比度 ✗ */
}
```

### 使用在线取色器的实用工作流程

#### 1. 从品牌 Logo 中提取颜色

如果你正在为客户建设网站，但只有他们的 Logo 图片，请使用取色器来采样主导色。大多数在线取色器允许你上传图片或使用吸管工具点击任意像素。一旦你获得了主要的 HEX 值，就可以在同一工具中使用 HSL 调整来创建完整的配色方案。

#### 2. 构建主题系统

从一个"品牌"色开始。使用取色器找到它的 HSL 值。然后，通过保持色相和饱和度不变、只调整明度来生成完整的色阶：

```
品牌色: hsl(239, 84%, 67%)     /* #6366F1 — 你的基础色 */
较浅: hsl(239, 84%, 90%)       /* #E0E7FF — 背景色 */
浅: hsl(239, 84%, 77%)         /* #A5B4FC — 悬停状态 */
深: hsl(239, 84%, 45%)         /* #4338CA — 激活状态 */
较深: hsl(239, 84%, 25%)       /* #1E1B4B — 浅色背景上的文字 */
```

许多现代框架如 Tailwind CSS 正是使用这种方法来创建它们的颜色色阶。

#### 3. 调试 CSS 颜色问题

有时候你的 CSS 看起来不对但你不确定为什么。也许你选的 `#F5F5F5` 与 `#FFFFFF` 太接近了。打开取色器，输入两个值，并排查看。工具会立即揭示它们实际上有多相似（或不同）。然后你可以锁定一个值并调整另一个，实时查看它们的关系变化。

### 常见问题

**问：HEX 和 RGB 有什么区别？**
答：HEX 是一种更紧凑的十六进制简写（`#FF5733` vs. `rgb(255, 87, 51)`）。RGB 使用更容易通过编程调整的十进制数字。它们表示完全相同的色彩空间。

**问：可以用在线工具从图片中取色吗？**
答：可以。[ToolboxPro 取色器](/tools/color-picker)包含吸管功能，让你可以点击浏览器窗口或上传图片中的任意像素来捕获其精确颜色值。

**问：主题化时 HSL 比 HEX 更好吗？**
答：通常是的。HSL 让你只需调整明度值就能轻松创建同一颜色的较浅和较深变体。使用 HEX，你需要为每个色调手动计算新值。

**问：在线取色器足够专业使用吗？**
答：当然。取色器使用与显示器和 Web 浏览器相同的 sRGB 色彩空间。对于印刷工作，你可能需要 CMYK 专用工具，但对于数字设计和开发，在线取色器已达到生产级水准。

**问：取色器的吸管工具是什么？**
答：吸管（或颜色采样器）让你可以点击屏幕或上传图片上的任意位置来捕获该像素的精确颜色。它是从现有设计或图片中逆向工程颜色的最有用功能之一。
