## 密码强度：如何在 2026 年创建和管理强密码

密码仍然是几乎所有在线账户的第一道防线——然而大多数人仍然在使用脆弱的、可猜测的密码。到 2026 年，撞库攻击变得更加复杂，一个被攻破的密码可能导致整个身份被接管。本指南解释了什么使密码变得强大、攻击者如何破解密码，以及如何使用免费的在线工具生成和管理坚不可摧的密码。

### 什么使密码变得强大？

一个强密码具有三个属性：**长度**、**不可预测性**和**唯一性**。让我们逐一拆解。

**长度至上。** 每增加一个字符都会使攻击者必须尝试的可能组合数呈指数级增长。一个 6 字符的小写字母密码有 3.08 亿种可能（26^6）。一个 12 字符的混合大小写、数字和符号的密码有 62 万亿亿种可能（94^12）。现代破解硬件可以在几秒内穷举短密码；而长密码则需要数百万年。

**不可预测性比复杂度规则更重要。** "P@ssw0rd!" 满足所有典型的复杂度要求——大写字母、小写字母、数字、符号——但它是攻击者首先尝试的猜测之一。密码破解工具使用泄露密码和常见替换的字典。随机的、机器生成的密码从根本上比任何人手选择的密码都更强。

**唯一性是不可协商的。** 跨网站重复使用密码是最危险的习惯。当一个网站被攻破时（它们终会被攻破），所有使用相同密码的其他账户都会立即变得脆弱。每个账户都应该有自己的独特密码。

|------|------|--------|------------------------|
| dog | 3 | 仅小写 | 即时 |
| iloveyou | 8 | 仅小写 | < 1 秒 |

### 攻击者如何破解密码

了解对手的方法有助于你正确防御。

**暴力破解。** 攻击者尝试每一种可能的字符组合。这是最慢的方法——使用当前硬件对 12+ 字符的随机密码进行纯暴力破解实际上是不可能的。攻击者只在万不得已时才会使用这种方法。

**字典攻击。** 攻击者不是尝试每种组合，而是尝试预编译列表（字典）中的单词。这包括常见单词、名称和泄露的密码数据库。这就是为什么 "football"、"princess" 和 "qwerty123" 会被即时破解——它们出现在每个破解者的字典中。

**基于规则的攻击（混合）。** 攻击者获取字典单词并应用转换规则：首字母大写、附加数字、将 "e" 替换为 "3"、"a" 替换为 "@"、"s" 替换为 "$"。这就是 "P@ssw0rd!" 被破解的方式——它遵循了每个破解者都知道的可预测替换模式。

**彩虹表。** 预计算的哈希链，可以逆转未加盐的密码哈希。如果网站使用弱哈希（MD5、SHA1）且无加盐来存储密码，彩虹表可以在毫秒内将哈希逆转为原始密码。现代网站使用加盐哈希（bcrypt、argon2），使彩虹表无效。

**撞库攻击。** 攻击者从数据泄露中获取用户名/邮箱和密码对，并在其他流行的服务上尝试它们。由于密码重复使用非常普遍，这种方法极为有效。仅在 2024 年，就有超过 20 亿条凭证在数据泄露中被泄露。

### 如何生成强密码

最强的密码是计算机生成的、完全随机的，并且包含混合的字符类型。这就是专用密码生成器工具变得不可或缺的地方。

以下是如何使用 JavaScript 以编程方式生成强密码的示例——与我们的在线工具使用的逻辑相同：

```javascript
function generatePassword(length = 16) {
  const upper = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ';
  const lower = 'abcdefghijklmnopqrstuvwxyz';
  const digits = '0123456789';
  const symbols = '!@#$%^&*()_+-=[]{}|;:,.<>?';
  const all = upper + lower + digits + symbols;

  // 确保每个类别至少有一个字符
  const required = [
    upper[Math.floor(Math.random() * upper.length)],
    lower[Math.floor(Math.random() * lower.length)],
    digits[Math.floor(Math.random() * digits.length)],
    symbols[Math.floor(Math.random() * symbols.length)],
  ];

  const remaining = Array.from({ length: length - 4 }, () =>
    all[Math.floor(Math.random() * all.length)]
  );

  // 使用 Fisher-Yates 洗牌
  const password = [...required, ...remaining];
  for (let i = password.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [password[i], password[j]] = [password[j], password[i]];
  }

  return password.join('');
}

// 示例输出："K8m$pL9xQ!vN2jR%tW5"
```

关键步骤是：
1. 分别定义大写字母、小写字母、数字和符号的字符池
2. 保证每个池至少有一个字符
3. 从完整字符池中随机填充剩余字符
4. 对整个结果进行洗牌，以避免可预测的前缀模式

### 密码管理最佳实践

即使是最强的密码，如果你无法记住或安全管理它，也是毫无用处的。以下是一个实用框架：

**1. 使用密码管理器。** 像 Bitwarden、1Password 或 KeePassXC 这样的应用为每个网站生成和存储独特密码。你只需要记住一个主密码。到 2026 年，密码管理器支持生物识别解锁、通行密钥（passkeys）和加密云同步，比以往任何时候都更加便利。

**2. 启用多因素认证（MFA）。** 强密码加上第二因素（TOTP 验证码、硬件密钥、生物识别）创建了纵深防御。即使你的密码被泄露，攻击者仍然无法在没有第二因素的情况下登录。优先使用硬件安全密钥（FIDO2/WebAuthn），而不是短信验证码，因为后者容易受到 SIM 交换攻击。

**3. 避免安全问题。** "你第一只宠物的名字是什么？"和"你在哪条街长大？"很容易被猜到或通过社交媒体发现。将安全问题答案视为额外的密码——要么使用存储在密码管理器中的随机答案，要么避免使用需要它们的服务。

**4. 定期检查泄露。** 像 Have I Been Pwned 这样的服务可以让你检查你的邮箱或密码是否出现在已知的泄露中。如果有，请立即更改该密码并在该账户上启用 MFA。支持通行密钥（WebAuthn）的网站提供了最强大的抗网络钓鱼认证。

**5. 绝不共享密码。** 任何合法的服务都不会通过电子邮件、电话或短信向你索要密码。如果你收到此类请求，那就是网络钓鱼企图。报告它，不要回复。

### 常见密码误区澄清

| 误区 | 真相 |
|------|------|
| 密码必须每 90 天更换一次 | NIST 现在**反对**强制定期更换——它们会导致更弱、更可预测的密码 |
| 越长的密码总是越好 | 长度很关键，但长的字典句子（如 "correct horse battery staple"）比短的随机字符串更弱，因为单词可以被破解 |
| 安全问题能增加真正的保护 | 安全问题答案通常是公开可发现的——将它们视为用户名，而不是密码 |
| 符号替换使密码变强 | "P@ssw0rd!" 使用了替换，但仍然在前几千次尝试中被猜出 |
| 密码生成器没有必要 | 人类无法生成真正随机的密码——机器生成对于真正的随机性至关重要 |
