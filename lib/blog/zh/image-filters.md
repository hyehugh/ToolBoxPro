## 什么是图片滤镜？

图片滤镜是修改图像像素以产生视觉效果的算法。从经典的黑白转换到艺术模糊和色彩偏移，滤镜让你无需 Photoshop 或专业编辑技能就能改变任何照片的情绪和风格。

滤镜通过操作像素值——调整亮度、对比度、色彩通道，或应用混合相邻像素的卷积矩阵——来工作。

## 常见图片滤镜详解

### 灰度

通过去除颜色信息将图像转换为黑白。每个像素的 RGB 值合并为单个亮度值：

```
Gray = 0.299 × R + 0.587 × G + 0.114 × B
```

这些权重符合人类感知——我们对绿色最敏感，对蓝色最不敏感。

**使用场景：** 创建经典外观，减少颜色带来的干扰，为黑白媒体打印准备图像。

### 怀旧（Sepia）

给图像赋予暖棕色调，让人联想到 19 世纪的照片。转换为灰度后，每个像素被染上暖色调：

```
输出 R = Gray × 1.2
输出 G = Gray × 0.93
输出 B = Gray × 0.55
```

**使用场景：** 创建复古、怀旧或具有历史感的图像。

### 反色

将所有颜色翻转到其在色轮上的对立面。黑色变为白色，红色变为青色，绿色变为品红色。

```
输出 R = 255 - 输入 R
输出 G = 255 - 输入 G
输出 B = 255 - 输入 B
```

**使用场景：** 创建负片效果、艺术构图，或面向可访问性的高对比度视图。

### 亮度

在所有 RGB 通道上添加或减去一个常数值：

```
输出 = 输入 + 亮度值
```

正值使图像更亮；负值使其更暗。结果被限制在 0-255 范围内。

**使用场景：** 校正曝光不足或过度的照片，匹配一系列图像的照明。

### 对比度

拉伸或压缩像素值的范围。高对比度使暗的更暗、亮的更亮；低对比度产生更平坦、柔和的外观：

```
输出 = ((输入 / 255 - 0.5) × 对比度因子 + 0.5) × 255
```

**使用场景：** 让图像更醒目（增加对比度）或创建柔和、梦幻的外观（降低对比度）。

### 模糊

将每个像素与其相邻像素平均，产生柔化效果。最常用的是**高斯模糊**，它使用加权平均，附近的像素比远处的像素影响更大：

```
// 一个 3×3 高斯核
[1, 2, 1]
[2, 4, 2]
[1, 2, 1] × (1/16)
```

**使用场景：** 模糊背景、遮挡敏感信息、创建景深效果或平滑肤色。

### 饱和度

控制颜色的强度。在 0% 时，图像为灰度。在 100% 时，颜色自然。在 200% 时，颜色鲜艳浓烈（有时称为"HDR 效果"）。

**使用场景：** 创建鲜艳的社交媒体图形（增加）或柔和、专业的视觉效果（降低）。

### 色相旋转

将所有颜色在色轮上按给定角度旋转。旋转 180 度会创建互补色方案。

**使用场景：** 快速更改调色板、创意效果或校正偏色。

## 如何在线应用滤镜

### 使用 ToolboxPro

1. 访问我们的[图片滤镜](/tools/image-filters)工具
2. 通过点击或拖放上传图片
3. 在工具栏中浏览可用滤镜
4. 点击任意滤镜立即应用
5. 调整强度滑块进行精细控制
6. 查看实时前后对比预览
7. 以 JPG、PNG 或 WebP 格式下载滤镜后的图像

### 可用滤镜

| 滤镜 | 作用 | 最适合 |
|--------|-------------|----------|
| 灰度 | 去除所有颜色 | 经典黑白摄影 |
| 怀旧 | 暖棕色调 | 复古照片 |
| 反色 | 反转所有颜色 | 负片效果 |
| 亮度 | 调整明度 | 曝光校正 |
| 对比度 | 拉伸色调范围 | 让图像更醒目 |
| 模糊 | 柔化细节 | 背景模糊 |
| 锐化 | 增强边缘 | 修复略模糊的照片 |
| 饱和度 | 调整颜色强度 | 鲜艳或柔和效果 |
| 色相旋转 | 偏移所有颜色 | 创意色彩变化 |
| 不透明度 | 调整透明度 | 叠加效果 |

## 进阶：叠加滤镜

真实的图片编辑很少只使用一个滤镜。尝试组合使用：

**复古肖像效果：**
1. 应用怀旧（强度：70%）
2. 降低对比度（-20%）
3. 添加轻微模糊（半径：1px）
4. 降低饱和度（60%）

**戏剧性黑白效果：**
1. 应用灰度
2. 增加对比度（+40%）
3. 增加锐化（强度：2）
4. 暗角效果（如可用）

**梦幻柔光效果：**
1. 应用模糊（半径：3px）
2. 降低对比度（-20%）
3. 增加亮度（+15%）
4. 降低饱和度（80%）

## Canvas API 方法

如果你是开发者，以下是使用 HTML5 Canvas API 应用灰度滤镜的方法：

```javascript
function applyGrayscale(imageData) {
  const pixels = imageData.data;
  for (let i = 0; i < pixels.length; i += 4) {
    const gray = 0.299 * pixels[i] + 0.587 * pixels[i+1] + 0.114 * pixels[i+2];
    pixels[i] = gray;     // 红色
    pixels[i+1] = gray;   // 绿色
    pixels[i+2] = gray;   // 蓝色
    // pixels[i+3] = alpha（不变）
  }
  return imageData;
}
```

## 常见问题

**图片滤镜会应用到原始文件吗？** 不会。滤镜应用到副本上。原始图像永远不会被修改——你随时可以重新开始。

**可以撤销滤镜吗？** 可以。我们的工具有撤销/重做堆栈，你可以随时重置为原始图像。

**最大图片尺寸是多少？** 我们的滤镜工具可以轻松处理最大 4096×4096 像素的图像。更大的图像可能取决于你的设备性能。

**滤镜对透明 PNG 有效吗？** 有效。Alpha 通道（透明度）在所有滤镜操作中都会保留。

**可以同时应用多个滤镜吗？** 可以。一次应用一个，每个滤镜在之前的结果上叠加。撤销堆栈允许你逐步回退单个滤镜应用。

**我的图片会上传到服务器吗？** 不会。所有滤镜处理都在你的浏览器中使用 Canvas API 运行。你的图片保留在你的设备上。
