## 什么是文本差异检查器？

文本差异检查器（"difference checker" 的简称）比较两段文本并高亮显示它们之间的不同。无论是审查代码更改、比较文档版本，还是检查抄袭，差异工具都能精确显示发生了什么变化——精确到单个字符。

差异工具是 Git 等版本控制系统的基本工具，但独立的差异检查器在你需要快速比较而又不想建立仓库时非常有用。

## 为什么要使用差异检查器？

- **代码审查**——部署前比较脚本的新旧版本
- **文档修订**——查看你的编辑器在合同中具体更改了什么
- **抄袭检测**——快速发现不同提交之间的抄袭内容
- **配置文件**——捕获配置备份中的意外更改
- **数据迁移**——验证源数据和目标数据在传输后是否匹配

## 差异检查的工作原理

### 逐行比较

最常见的模式。每一行被比较，工具会显示：

- **绿色**（新增）——新文本中有但旧文本中没有的行
- **红色**（删除）——旧文本中有但新文本中没有的行
- **白色**（未更改）——两个版本中完全相同的内容

### 字符级别比较

对于详细的编辑，字符差异显示一行*内部*的变化。如果你将 "colour" 改为 "color"，行差异显示整行已更改，但字符差异仅高亮显示 "u" 被删除、"r" 被添加。

### 单词级别比较

介于行和字符之间。增加和删除按单词显示，而非按字符——非常适合散文和文档。

## 如何使用差异检查器

### 第一步：准备文本

将原始文本复制到左面板，修改后的文本复制到右面板。顺序很重要——工具显示从*左*到*右*发生了什么变化。

### 第二步：立即比较

大多数差异工具在你输入或粘贴时会实时更新。无需点击任何按钮——高亮立即显示。

### 第三步：审查输出

浏览高亮显示的差异：

| 颜色 | 含义 | 检查内容 |
|-------|---------|---------------|
| 绿色 | 新增行 | 验证新内容是否正确 |
| 红色 | 删除行 | 确认删除是有意为之 |
| 黄色高亮 | 行内修改 | 仔细检查修改的单词/字符 |

### 第四步：复制或合并

满意后，你可以：
- 将结果复制到剪贴板
- 下载差异报告
- 手动应用更改

## 实际示例

### 示例 1：文档修订

**原文：**
```
敏捷的棕色狐狸跳过了懒狗。
```

**修订版：**
```
敏捷的棕色狐狸跃过了懒猫。
```

**差异结果：**
- 第 1 行："跳" → "跃"（单词级别变化）
- 第 1 行："狗" → "猫"（单词级别变化）

### 示例 2：代码更改

**之前：**
```javascript
function greet(name) {
  return "Hello, " + name;
}
```

**之后：**
```javascript
function greet(name, time) {
  return `Good ${time}, ${name}`;
}
```

**差异结果：**
- 函数签名中添加了参数 "time"
- 返回字符串从拼接改为模板字面量
- 两行完全更改

## 差异算法解释

大多数差异工具（包括我们的）使用**最长公共子序列（LCS）**算法。它找到在两个文本中以相同顺序出现的最长字符序列，然后将其他所有内容标记为更改。

现代实现还使用**Myers 算法**，该算法针对代码差异进行了优化，通过优先选择连续的更改块而非分散的单行差异，产生更易读的输出。

## 获得清晰差异的技巧

1. **标准化空白**——尾随空格和不一致的缩进会产生误报
2. **修剪空行**——开头或结尾多余的空行会显示为添加/删除
3. **使用一致的行结尾**——Windows（CRLF）与 Unix（LF）的差异不可见，但会显示为整行更改
4. **对输入进行排序**——对于无序列表，比较前对两边进行排序可减少干扰

## 常见问题

**比较区分大小写吗？** 默认是区分大小写的。大多数差异工具在只关心内容而非大小写时提供"不区分大小写"的开关。

**可以比较非常大的文件吗？** 可以。我们的差异检查器可以轻松处理高达 1MB 的文件。对于更大的文件，性能取决于你的浏览器内存。

**它适用于代码与纯文本的比较吗？** 适用于任何文本。编程语言适合逐行视图，而散文更适合单词级别视图。

**我的文本会上传到服务器吗？** 不会。所有操作都在你的浏览器中使用 JavaScript 运行。你的数据不会离开你的设备。

**统一差异和并排差异有什么区别？** 统一差异在单列中显示更改并附有上下文行。并排差异（我们的工具使用的）同时显示两个版本——对大多数用例来说更容易阅读。
