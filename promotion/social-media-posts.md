## 四、掘金帖子

### 标签: 前端 / 开源 / 工具

**标题:**
分享一个我做的 100+ 免费在线工具箱，全部浏览器端运行

**正文:**
### 背景

平时开发经常需要各种小工具：格式化 JSON、测试正则、压缩图片、合并 PDF……每次都要找不同的网站，索性自己做了一个集成站。

### 介绍

[TryToolboxPro](https://trytoolboxpro.com) 是一个包含 100+ 免费在线工具的网站，核心理念是**隐私优先**——所有文件处理都在浏览器本地完成，不上传服务器。

### 工具分类

**开发者工具（25+）**
- JSON 格式化 & 验证
- 正则表达式测试
- JWT 解码/生成
- CSS 渐变/阴影生成器
- SQL 格式化
- JSON → TypeScript 接口生成
- Markdown → HTML 转换
- CSV 查看器

**图片工具（20+）**
- 图片压缩（JPEG、PNG、WebP）
- 格式转换（JPG ↔ PNG ↔ WebP ↔ AVIF）
- 裁剪、缩放、翻转、旋转
- GIF 制作
- 水印添加
- 拼图/拼接
- 素描效果

**PDF 工具（5）**
- 合并、拆分、旋转、删除页面
- 图片转 PDF

**文本工具（15+）**
- 字数统计、大小写转换、文本对比
- Lorem Ipsum 生成器
- 摩尔斯电码转换
- 凯撒密码加解密

**日常工具（15+）**
- 二维码生成器
- 密码生成器
- 小费计算器
- 单位换算（温度、长度、重量、速度、面积）
- 时区转换器

### 技术实现

```
技术栈: Next.js 15 + TypeScript + Tailwind CSS
部署: Vercel (Static Export)
图片处理: Canvas API + browser-image-compression
PDF 处理: pdf-lib (浏览器端)
国际化: React Context (中/英)
```

**关键设计决策：**

1. **零服务器依赖**：所有文件处理在浏览器完成，用 Canvas API 处理图片，用 pdf-lib 处理 PDF
2. **无需注册**：打开即用，降低使用门槛
3. **静态部署**：Next.js Static Export，全球 CDN 加速
4. **隐私合规**：不上传文件，不存储用户数据

### 为什么做这个

市面上的工具站大多需要上传文件到服务器，对于敏感文件（合同、身份证照片等）不太放心。这个站的设计就是：**你的文件永远不会离开你的浏览器**。
