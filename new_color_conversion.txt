## Why Color Conversion Matters

Designers think in HEX. Developers prototype in RGB. CSS animations use HSL. If you work with colors, you need all three formats.

Color conversion is essential when moving between design tools (Figma, Sketch), code editors, and CSS stylesheets. A color that looks right in HEX might need to be expressed as RGB for canvas operations, or as HSL for programmatic adjustments like darkening or lightening.

## Common Color Formats

### HEX (Hexadecimal)

Used in HTML and CSS. Starts with `#` followed by 6 hex digits (00-FF for each channel):

```
#FF5733  →  Red: FF (255), Green: 57 (87), Blue: 33 (51)
```

**When to use HEX:** CSS stylesheets, design handoffs, color palettes. It's the most compact representation — 7 characters instead of RGB's 13.

**Shorthand notation:** Colors like `#FF5733` can sometimes be shortened to `#F53` if each channel is a repeated pair (FF, 55, 33 → F, 5, 3). But `#573` would be incorrect for the example above.

### RGB (Red, Green, Blue)

Uses decimal values (0-255) for each channel, plus an optional alpha channel for transparency:

```
rgb(255, 87, 51)
rgba(255, 87, 51, 0.5)
```

**When to use RGB:** JavaScript canvas operations (ctx.fillStyle), image processing algorithms, design tools like Photoshop and Figma. RGB is the native language of computer screens — every pixel emits red, green, and blue light at specific intensities.

### HSL (Hue, Saturation, Lightness)

More intuitive for human adjustments. Describes color in terms humans naturally think about:

```
hsl(11, 100%, 60%)
```

| Component | Range | What it represents |
|-----------|-------|-------------------|
| Hue | 0°-360° | The base color (0=red, 120=green, 240=blue) |
| Saturation | 0%-100% | Intensity of the color (gray → pure) |
| Lightness | 0%-100% | Brightness (black → white) |
| Alpha | 0-1 | Transparency (optional, hsla format) |

**When to use HSL:** Creating color themes, dark/light mode toggles, generating color variants. HSL makes it trivial to create a darker shade — just reduce lightness by 10%. In RGB, you'd need to adjust all three channels proportionally.

## Color Theory Basics

### The Color Wheel

The HSL hue values correspond to the traditional color wheel:

- **Red:** 0° — primary
- **Yellow:** 60° — primary
- **Green:** 120° — primary
- **Cyan:** 180° — secondary
- **Blue:** 240° — primary
- **Magenta:** 300° — secondary

### Complementary Colors

Colors opposite each other on the wheel (180° apart) are complementary. For example, blue (240°) and yellow (60°). Using complementary colors creates high contrast and visual tension — useful for call-to-action buttons.

### Analogous Colors

Colors next to each other on the wheel (30-60° apart) create harmonious, low-contrast palettes. For example, blue (240°), teal (210°), and green (180°).

### Manual HEX to RGB Conversion

1. Split the HEX string into 3 pairs: `#FF`, `57`, `33`
2. Convert each pair from hexadecimal to decimal:
   - `FF` = 15×16 + 15 = 255
   - `57` = 5×16 + 7 = 87
   - `33` = 3×16 + 3 = 51
3. Result: `rgb(255, 87, 51)`

### Manual RGB to HSL Conversion

1. Find the min and max of R, G, B (0-1 range)
2. Lightness = (max + min) / 2
3. If max = min, saturation = 0 (achromatic)
4. Otherwise, saturation depends on lightness
5. Hue depends on which channel is max: 0° for red, 120° for green, 240° for blue, with adjustments for the other channels

This is tedious to do by hand — use our converter instead!

## FAQ

**What's the difference between HEX and RGB?** They represent the same colors differently. HEX is base-16 (00-FF per channel); RGB is base-10 (0-255 per channel). Both describe amounts of red, green, and blue light.

**Why does my color look different on different screens?** That's a hardware/calibration issue, not a format issue. HEX, RGB, and HSL should all display identically on the same screen. Different monitors have different color gamuts and brightness levels.

**What is color contrast ratio?** It measures readability of text against a background. WCAG AA requires 4.5:1 for normal text. Our tool shows contrast ratios automatically when you enter two colors.

**Should I use HEX or HSL in my CSS?** Use HEX for static colors (brand palette) and HSL for dynamic colors (hover states, themes). HSL's `hsl(var(--hue), 80%, 50%)` lets you change a theme's hue in one CSS variable.

**Can I convert CMYK to HEX?** CMYK is a subtractive color model used for printing. To convert CMYK to HEX, you first convert to RGB (using color profiles), then to HEX. Our tool supports CMYK input as well.

**What's the alpha channel?** It controls transparency. RGBA and HSLA add a fourth value (0 to 1, or 0% to 100%). A 6-digit HEX code has no alpha; 8-digit HEX (e.g., `#FF573380`) includes alpha in hex format.
